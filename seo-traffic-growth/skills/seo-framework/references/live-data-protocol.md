# 活数据获取协议（取数顺序与数据源清单）

> 解决问题：选题评分卡的「搜索量得分」「竞争度得分」等因子需要真实数据输入。拍脑袋给分 = 公式沦为装饰。本协议定义取数顺序与数据源字段清单。

## 一、取数顺序（铁律，按优先级）

```
用户提供 > 实时检索 > 库内基准 > 标【待核实】
```

1. **用户提供**：用户手上有 5118/新榜/百度指数/微信指数/后台数据时，优先采用，追问缺失字段。
2. **实时检索**：用户没有数据时，用 WebSearch/WebFetch 查实时公开数据（搜索量区间、SERP 构成、平台指数），必须标注来源 + 年份 + 口径。
3. **库内基准**：benchmarks.md 的静态数据只用于「行业常识级」判断（如 CTR 量级），不可用于具体词的搜索量。
4. **标【待核实】**：以上都拿不到时，给出基于假设的评分，但显式标注假设值与【待核实】，并告诉用户「拿到 X 数据后评分会如何变化」。

**禁止**：凭训练记忆直接报具体词的搜索量/指数数值。

## 一-补、数据新鲜度 TTL 分级（v1.4 新增）

不同数据衰减速度不同，按 TTL 决定是否必须现查：

| 数据类型 | 衰减速度 | 核实频率 | 说明 |
|---|---|---|---|
| 平台算法规则 / 政策 / 违禁词执法口径 | 极快 | **用前必查（周级）** | 平台规则常变，凭记忆必踩坑 |
| AI 摘要(AIO)覆盖率 / CTR 基准 | 快 | 季度 | benchmarks.md 第〇节定期复核 |
| 关键词搜索量 / 指数 | 中 | 月级 | 趋势词衰减快， evergreen 词稳定 |
| 竞品占位 / 行业格局 | 中 | 月级 | 配合 geo-monitoring 自测 |
| 学术原理 / 传播学模型 | 慢 | 年级 | first-principles.md 相对稳定 |

## 一-补2、AI 引用自测 = 一等数据源（v1.4 新增）

评估"这个词/这篇能不能被 AI 引用"时，**最硬的数据不是推算，是自测**：直接把目标 query 问 Perplexity/元宝/ChatGPT/Kimi，看实际引用了谁、什么结构。流程见 geo-monitoring.md。它比任何关键词工具都更接近 GEO 真相，因为 AI 引用源与谷歌 Top10 重合度已 <20%（benchmarks.md 第〇节）——传统工具测不到这个。

## 一-补3、双渠道实时扫描源清单（v1.6 重构：海外为主、国内为辅）

做热点预警 / 网感雷达 / 趋势判断时，按「国外 + 国内」双渠道扫描。**信源策略：海外为主（约 80%）、国内为辅**——海外一手源（论文/机构报告/官方/海外媒体）是论断的主要依据，国内源仅用于国内事件验证与国内平台生态补充，不得以国内二手转述代替海外一手源。

### 海外（主渠道，优先扫）
| 类别 | 扫描源 | 用途 |
|---|---|---|
| 学术·论文 | arXiv（cs.IR / cs.AI / cs.CL 每周新提交）、ACL/EMNLP/KDD 论文集 | GEO/Agent 前沿论断的唯一「学术级」依据；论文清单见 research-library.md |
| 社区·讨论 | Reddit（r/artificial、r/LocalLLaMA、r/singularity）、Hacker News、X/Twitter 趋势 | 大基数用户真实讨论、模型口碑、爆点酝酿地（AI 偏爱社区内容：OpenAI-Reddit 年授权 6000 万美元） |
| 产品·发布 | Product Hunt 每日热榜、Hacker News 首页 | Agent 基建新产品（IDE/浏览器/搜索/支付/采购）与可产业化信号 |
| 数据·研究站 | Artificial Analysis、Semrush/BrightEdge/SparkToro、SE Ranking、Sensor Tower | SEO/GEO 基准、AI 搜索份额、模型评分、MAU 数据 |
| 媒体·财经 | TechCrunch、The Verge、Bloomberg、WSJ、dev.to AI Daily Digest | 融资 / 美股 / 产品周报 |
| 机构·报告 | Gartner / McKinsey / Forrester / Deloitte / Anthropic 官方报告 | 产业 ROI 与采用率硬数据（见 research-library.md 第三节） |

### 国内（辅渠道，验证用）
| 类别 | 扫描源 | 用途 |
|---|---|---|
| 热榜 | 微博热搜、知乎热榜、百度热搜、抖音热点 | 话题突变第一信号源（仅作触发信号，数据仍回海外/一手核实） |
| 行业媒体 | 量子位、机器之心、晚点 LatePost、36氪、钛媒体、新榜 | 国内事件一手验证与国内平台生态补充 |

纪律：以上均为「扫描起点」，引用其数据仍须回到一手来源核实；扫不到就标【待核实】。**GEO 引用率/效果类论断引用前必须过 research-library.md 的批判综述校正**（如「+40%」必须加「固定上下文内」条件）。

## 二、向用户索取数据的字段清单（按场景）

### 选题/关键词评估（让用户从 5118、爱站、百度指数导出）
| 字段 | 说明 | 影响因子 |
|---|---|---|
| 目标词月搜索量 | 近 30 天或近 12 个月均值 | 搜索量得分 |
| 搜索量趋势 | 近 12 个月曲线方向（升/平/降） | 中长周期价值 |
| SERP 首页域名列表 | 判断大站占比 | 竞争度得分 |
| 该词是否触发 AI 摘要 | 是/否 + 摘要信源是谁 | 意图权重、引用潜力 |
| 长尾变体列表 | 下拉词/相关词 | 挖词分层 |

### 公众号/内容账号诊断（让用户从后台截图或导出）
| 字段 | 说明 |
|---|---|
| 近 30 天各篇打开率、完读率、分享率 | 校准标题与选题权重 |
| 粉丝净增/取关率 | 定位健康度 |
| 搜一搜来源阅读占比 | SEO 渗透 |
| 品牌词微信指数趋势 | 品牌资产 |

### 小红书/知乎/官网
- 小红书：笔记点击率、收藏率、搜索来源占比、目标词搜索下拉占位
- 知乎：回答赞同/收藏、问题关注人数、搜索卡位、被 AI 引用情况
- 官网：GA/GSC 的 CTR、排名、展示量；AI 引荐流量（ChatGPT/Perplexity/元宝来源）与转化率

## 三、无数据时的降级评分模板

```
【假设输入】月搜索量假设为 1k-1万 档（得分 3）【待核实】
【敏感性】若实际 <1k（得分 2），选题分从 X 降至 Y，结论不变/改变为 ___
【验证动作】在 5118 查「关键词」→ 把月搜和趋势发我，我 30 秒内重算
```

关键：**给出敏感性分析**——告诉用户哪个数据会改变结论，让"要数据"这个动作有明确 ROI。

## 四、数据入库

用户提供的账号级数据，按 account-profile-schema.md 写回基线；行业级新数据（如新的 CTR 研究）提示用户后可更新 benchmarks.md，保持弹药库不过期。
