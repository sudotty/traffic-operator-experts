# GEO 引用自测与监测 SOP（实测，不是理论）

> GEO 效果不能只靠概率模型推算，要**实测**：你的内容/品牌到底有没有真的被 AI 引用。这是 2026 最直接的 GEO 测量手段，且立刻可做。本 SOP 把"AI 引用率"从口号变成可追踪的北极星指标。

## 一、自测流程（每篇发布后 72h + 每周固定一次）

### 第 1 步：定 query 集
- **品牌词**：你的品牌名 / 账号名 / 栏目名（2-3 个）
- **目标关键词**：本周内容主攻的 5-10 个词
- **长尾问题**：用户真实会搜的 3-5 个问题（"XX 怎么选""XX 哪个好"）

### 第 2 步：逐条问 AI 引擎
把每个 query 分别问：**Perplexity / 腾讯元宝 / ChatGPT / Kimi / 豆包**（覆盖国内外主流）。
- 方式：WebFetch 抓取答案，或在对应 App/网页直接问
- 注意：同一 query 在不同引擎、不同时间答案会变，记录引擎与时间

### 第 3 步：四维记录每条结果
| 维度 | 记录什么 |
|---|---|
| **被检索到？** | AI 答案是否涉及你的主题/数据/观点（哪怕没署名） |
| **被引用？** | 是否明确出现你的品牌名/链接/账号 |
| **引用形式** | 直接放链接 / 提及品牌 / 用了你的数据但没署名（"暗引用"） |
| **竞品占位** | AI 实际引用了谁（如果不是你）——这就是你的对标对象 |

### 第 4 步：对照 GEO 概率模型诊断最弱环
- 没**被检索到** → 结构/爬虫问题：检查是否屏蔽 AI 爬虫、chunk 是否自包含
- 检索到没**被选中** → 信息增益/结构问题：补独家数据、加 40 字结论块、FAQ
- 选中没**被归因** → 实体一致性：品牌名/作者/出处要全篇统一清晰

## 二、计分卡与趋势

```
AI 引用率 = 被引用 query 数 ÷ 总 query 数
```

| query | 引擎 | 被检索 | 被引用 | 引用形式 | 竞品占位 | 最弱环 |
|---|---|---|---|---|---|---|
| 品牌词X | 元宝 | ✓ | ✓ | 直接链接 | 无 | — |
| 关键词Y | ChatGPT | ✓ | ✗ | — | 竞品A | 被选中 |

- **追踪周环比**：AI 引用率涨没涨？哪类 query 突破了？
- 记录到账号基线（account-profile-schema.md），纳入北极星看板

## 三、冷启动反向拆解（还没有内容被引用时）

还没被引用？反向用这个流程**偷师**：
1. 把目标 query 问 AI，看它**引用了谁**
2. 拆解那个信源的结构：是不是 40 字结论块？FAQ？数据密度多高？实体多清晰？
3. **抄结构，不抄内容**（版权红线，见 compliance.md）——把被验证有效的 GEO 结构移植到你的内容上

## 四、与归因节奏联动

- AI 引用率是每周归因（attribution-rhythm.md）的**第一北极星指标**，先于阅读量看
- 自测发现的"有效 GEO 结构"沉淀进 style-anchors.md，转化为可复用资产
- 竞品占位分析回流给选题：竞品在哪个 query 占了位，就是你下一个内容簇的突破口

## 五、纪律

1. **实测优先于推算**：概率模型指导方向，自测结果才是真相。两者冲突时信自测。
2. **记录口径**：同一 query 必须带引擎 + 时间戳，否则无法比趋势（AI 答案有时效）。
3. **不编造结果**：没测就说没测，禁止凭印象说"我应该被引用了"。
