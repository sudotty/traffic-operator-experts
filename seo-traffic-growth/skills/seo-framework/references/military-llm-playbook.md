## Part 0｜总纲：现代军事学终极公式 → LLM 工程公式

> **军事公式：胜利 = f（决策速度，信息熵减，网络弹性）**（Boyd/Alberts/Warden 综合）
> **LLM 映射：Agent 竞争力 = f（推理效率，上下文信噪比，系统鲁棒性）**

三条主线贯穿全部 35 概念：①决策速度 → 推理时缩放 + 多智能体（L1/L5）；②信息熵减 → 上下文工程 + RAG（L2/L4）；③网络弹性 → 工具调用 + 对齐（L3/L6）。

## Part 2｜LLM/Agent 第一性原理（6 大工程定律）

| # | 定律 | 数学/工程本质 | 瓶颈 | SOTA 技术 |
|---|---|---|---|---|
| L1 | **推理时计算缩放** | 推理期投入更多计算（搜索/采样/RM），边际收益>扩参数 | 延迟&算力 | o1 / AlphaProof / ToT |
| L2 | **上下文熵与注意力复杂度** | 上下文越长注意力 O(n²)；位置偏差→Lost-in-Middle | 窗口限制&KV Cache | RoPE / GQA / Infinite-Transformer |
| L3 | **工具收敛与动作空间映射** | 文本输出→结构化 API 调用（概率空间离散化） | 函数幻觉 | Toolformer / Function Calling / DSPy |
| L4 | **参数化记忆 vs RAG** | 权重存储 vs 外部检索分离；Recall=生成质量上限 | 分块语义破坏 | Self-RAG / RAPTOR / HyDE |
| L5 | **多智能体通信损耗** | 通信耗 Token，易陷共识循环；博弈均衡=理想态 | 通信开销&收敛 | AutoGen / MetaGPT / Debate |
| L6 | **对齐与奖励稀疏性** | RM 只给标量分数，缺过程监督/意图路径 | 偏好冲突 | RLHF / DPO / Constitutional AI |

## Part 3｜匹配度矩阵（Gap 低估指数 TOP8）

> 评分：匹配度 1-10（映射深度）；产业重视度 ⭐1-5（调研估算）；**低估指数 Gap = 匹配度 - 重视度折算**，Gap 越大越被低估。

| 军事概念 | LLM 映射 | 匹配度 | 产业重视度 | **Gap** | 结论 |
|---|---|---|---|---|---|
| **M16 马赛克战** | L1 推理时缩放 + L5 多智能体 | 9.5 | ⭐⭐ | **+7.5** | **严重低估**：当前 MoE 是预训练层静态分专家；马赛克=推理时动态组合碎片（<1B 专精模型联邦），成本/效能比远超单体大模型 |
| **M13 认知战 NATO** | L6 对齐 + 提示注入防御 | 9.0 | ⭐ | **+8.0** | **严重低估**：认知战=主动改变对手置信度/风险感知；只被当安全底线，未作主动策略（认知对抗/情报护城河） |
| **M8 ACH** | L1 推理搜索 + L6 校准 | 9.0 | ⭐ | **+7.5** | **严重低估**：CoT 是单一故事线；ACH 强制 3-5 个互斥假设+诊断证据排除=新 Debug 范式 |
| **M26 边缘组织** | L5 多智能体拓扑 | 8.5 | ⭐ | **+7.5** | **严重低估**：当前是星型主控；边缘组织=网状全连通，VUCA 下生存率远高星型 |
| **M17 侦察-打击综合体** | L4 RAG + L3 工具 | 9.0 | ⭐⭐⭐ | **+6.0** | **低估**：RAG 中间隔 LLM 理解层；侦察-打击=传感器直连执行（0 延迟反射弧，小模型+规则即可） |
| **M2 任务式指挥** | L6 RLHF/过程监督 | 8.0 | ⭐⭐ | **+6.0** | **低估**：RLHF 只有标量奖励；任务式指挥=传"意图文档"（Intent Manifest）而非具体步骤 |
| **M15 杀伤网** | L3 工具 + L5 多智能体 | 8.5 | ⭐⭐⭐ | **+5.5** | **高估静态链低估动态网**：LangChain 固定 DAG vs 杀伤网任意节点连接任意射手（事件流订阅式自愈） |
| **M6 ISR + M12 熵减** | L4 RAG + L2 上下文压缩 | 9.5 | ⭐⭐⭐⭐ | **+5.0** | **低估终极目标**：RAG 只追 Recall，未追"决策熵减"——输出应带不确定性区间 |

## Part 4｜三枚战略核武器（产品方案，可直接开发）

### 🏆 Top 1：Mosaic-Router（马赛克路由）—— 动态稀疏推理
- **军事原型**：M16 马赛克战（DARPA/CSBA）——动态组合低成本碎片形成涌现效果。
- **问题**：业界迷信"大模型全能"，忽略碎片化微型模型动态拼装的成本优势。
- **产品**：轻量路由 LLM（<1B）收到任务后动态调度：① SQL 模型（1B）取数据 → ② 代码模型（2B）清洗 → ③ 报表模型（2B）渲染。推理成本仅为 GPT-4 级模型的 **1/20**。
- **预期收益**：企业 AI 推理成本 ↓90%；可解释性 ↑200%（每个碎片逻辑清晰）；容错性 ↑（碎片可替换）。
- **对应 L 定律**：L1（推理时缩放）× L3（工具路由）。
- **落地形态（流量操盘）**：内容产线 Mosaic——选题分析（1B）→ 大纲生成（2B）→ 数据填充（RAG）→ 合规校验（规则+小模型）→ 质检（Judge 模型），按环节路由，替代"一个大模型干所有"。

### 🥈 Top 2：Cognitive Shield（认知盾）—— 对抗性认知防御
- **军事原型**：M13 认知战（NATO SAS-114）+ M34 OPSEC + M35 MilDec。
- **问题**：认知战只被用来防守，没被用来主动保护商业情报。
- **产品**：AI 自动识别竞品爬虫 UA，动态返回"高置信度错误答案"（如价格偏移 +5%）；真实用户返回准确数据。
- **预期收益**：竞品数据采集失真率 ↑60%；建立非对称商业情报壁垒。
- **对应 L 定律**：L6（对齐/安全）× L3（请求识别工具）。
- **合规边界（重要）**：仅用于"区分爬虫与真人"的访问策略；不得用于欺骗真实用户（合规 > 用户目标）；须符合平台反爬条款与广告法（见 compliance.md）。【经验判断：此为灰色地带，需法务评估后实施】

### 🥉 Top 3：ACH-Debugger（竞争假设调试器）—— 多假设根因定位
- **军事原型**：M8 ACH（Heuer 1999）。
- **问题**：线性 CoT 教不会 LLM"怀疑自己"。
- **产品**：每次故障，Agent 强制生成 3 个根因假设，自动并行执行验证脚本（如 ping DB/查连接池），按证据打分。
- **预期收益**：根因定位（MTTI）30 分钟→2 分钟；误判率 ↓70%。
- **对应 L 定律**：L1（推理搜索）× L6（校准）。
- **落地形态（流量操盘）**：GEO 自测的 ACH 化——"为什么没被引用"三假设（检索环没进/选中环没选/归因环没署名），并行自测验证，取代单一路径归因。

## Part 7｜三大研究方向（学术界/产业界应重仓）

1. **动态稀疏化推理（Dynamic Sparse Inference）**——不卷单一千亿模型；研究"运行时动态路由的小模型联邦"：成本降一个数量级、容错更高、AI 普惠唯一出路（M16 马赛克战的工程化）。
2. **对抗性认知对齐（Adversarial Cognitive Alignment）**——安全对齐升级为主动认知防御：让模型识别信息操控并反向瓦解（M13 认知战）。
3. **过程监督与意图嵌入（Process-Supervision with Intent）**——放弃仅标量奖励的 RLHF，引入"指挥官意图"作为高维约束：让 Agent 有原则而非有分数（M2 任务式指挥 → 解决长尾任务崩溃）。

## Part 8｜边界与反例（本专家纪律：军事映射的限度）

1. **映射 ≠ 等同**：军事概念映射 LLM 是"启发式对齐"，不是"证明等价"——马赛克战的动态拼装是否适用于 LLM 路由，需实证（碎片间信息损失、路由开销）；标【推断】处不可当结论引用。
2. **认知战的双刃剑**：M13 主动欺骗（认知盾）涉合规红线——仅限"爬虫 vs 真人"区分，绝不可欺骗真实用户；任何实施前过 compliance.md + 法务。
3. **OODA 2.0 的人类参与**：熵过高强制提升人类权重（M32 战争迷雾）——不能把"不确定场景"交给全自动 Agent。
4. **马赛克 ≠ 无主脑**：任务式指挥（M2）要求"意图+边界"，马赛克碎片仍需统一的指挥意图——去中心化执行 ≠ 无中心目标。
5. **过度军事化风险**：把一切竞争当"战争"会诱发零和思维；流量操盘多数场景是"非零和增长"，军事映射用于"对抗性场景"（竞品/攻击），不用于"合作性场景"（用户关系/生态）。
