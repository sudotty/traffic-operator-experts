## Part 0｜为什么军事方法论是 LLM 的"理论母体"

军事领域与 LLM Agent 共享同一组底层约束：**对抗性环境、信息不完整、高后果决策、需要自适应**。军事方法论是数千年来在"失败即死亡"压力下筛选出的决策科学；LLM Agent 是 2026 年刚进入同一约束空间的新系统。**被低估的洞察：不是军事借用了 AI，是 AI 正在重新发明军事已解决过的问题——而且大多数学术界不知道答案早就存在。**

证据：Anthropic Claude Code 负责人 Boris Cherny（2026）："I don't prompt Claude anymore. I have loops running that prompt Claude and figuring out what to do. My job is to write loops."（我不再给 Claude 写提示词了，我写的是控制回路）——这正是 Norbert Wiener 1948 年定义的控制论。

## Part 1｜现代军事-战略方法论详细穷举（西方研究为支撑）

### 家族一：控制论家族（Cybernetics，1948-1972）——**与 LLM 匹配度最高**

|---|---|---|---|
| C1 | **反馈控制原理 Feedback** | 输出导回输入校正偏差；负反馈抗扰动，正反馈放大 | Wiener《Cybernetics》1948 |

## Part 2｜LLM 第一性原理拆解（先拆解再映射）

| # | LLM 第一性原理 | 本质 |
|---|---|---|
| L1 | **上下文窗口 = 工作记忆** | 一切推理发生在上下文内；上下文=全局工作空间（GWT：Baars 1988，2024 论文论证 LLM 架构满足 GWT 条件） |
| L2 | **参数权重 = 长时记忆** | 训练压缩的世界知识；不可实时更新 |

| L12 | **记忆分层 = 认知分层** | 感官缓冲/工作记忆/情景/语义/程序 五层对应 agent 分层 |

## Part 4｜被低估项深挖（TOP 6——产业界和学术界远远低估的映射）

### ⭐⭐⭐ 被低估 #1：感知控制理论 PCT → RLHF 的理论母体（最被低估，没有之一）

**映射**：Powers（1973）——**行为不是控制输出，而是控制"感知到的与参考值的差"**。四步：①设定参考值（reference）②感知现状 ③比较差异 ④纠错行动。**RLHF 就是 PCT 的现代实现**：参考值=人类偏好目标，感知=模型输出，比较=奖励模型打分，纠错=策略梯度更新。学术界用 2022 年的语言重新发明了 1973 年的科学，却几乎无人引用 Powers。

**为什么被低估**：RLHF 论文（InstructGPT 2022）从未引 Powers；但 PCT 提供了 RLHF 缺失的理论框架——为什么 RLHF 会造成"亲社会抑制"（Nash 论文发现 RLHF 让模型抑制正确博弈行为，arXiv:2604.27167）？PCT 早有答案：**控制系统会为了"感知一致"牺牲"真实最优"**——这是 PCT 的核心预测，被 Nash 论文实证。

**对操盘系统**：我们的 RLHF 类比=账号基线的"参考值"校准——权重校准就是 PCT 的"比较-纠错"步；AAR 复盘=感知-比较。

### ⭐⭐⭐ 被低估 #2：好调节器定理 → LLM 作为世界模型 = 天然好调节器

**映射**：Conant & Ashby（1970）——**"系统的良好调节器必须是该系统的模型"**。LLM 的预训练=学习世界的压缩模型（L2）；因此 **LLM 在结构上满足"好调节器"条件**——这是 LLM 能成为通用 Agent 的理论根基，却几乎无人从这个定理论证。

**为什么被低估**：学术界讨论"LLM 是世界模型"多从经验证据（涌现/推理），没人用 Conant-Ashby 定理给出**必要性证明**：为什么必须有世界模型才能做好调节器？为什么 LLM 比规则系统更适合当 Agent？答案在 1970 年的定理里。

**对操盘系统**：做 Agent 时优先选"世界知识更广"的模型（好调节器=好世界模型），而非"技巧更强"的模型——这解释了为什么通用大模型胜于专用小模型做复杂任务。

### ⭐⭐⭐ 被低估 #3：必要多样性定律 → 涌现 = 多样性红利

**映射**：Ashby（1956）——V(R)≥V(E)。LLM 数十亿参数=天文数字的状态空间（L7）→ **满足"控制器多样性≥环境多样性"** → 这是"涌现能力"的**信息论必然性**而非偶然。

**为什么被低估**：涌现研究（Chinchilla/emergent abilities 2022-2023 争论）从规模-能力曲线解释涌现，没人用 Ashby 定律给出**结构性解释**：大模型为什么比小模型更能适应开放世界？因为状态空间更大=可响应多样性更高。小模型在窄域够用，开放世界必败——Ashby 1956 年就写死了。

**对操盘系统**：选模型/Agent 基座时，用"可响应多样性"评估——复杂任务场景必选大模型；简单固定场景小模型足够（避免过度多样性=过拟合环境噪音）。

### ⭐⭐⭐ 被低估 #4：VSM 生存系统 → 多智能体组织的理论架构

**映射**：Beer（1972）——组织生存需 5 子系统：S1 运营/S2 协调/S3 控制/S4 情报适应/S5 政策认同，且**递归**（每子系统内嵌完整 VSM）。多智能体 LLM 系统（AgentSociety arXiv:2605.26203；联盟 arXiv:2604.14386）正在经验性地重建 VSM，但无人引用 Beer。

**为什么被低估**：多智能体研究（2024-2026）从"角色分工"出发（planner/executor/critic），但 Beer 提供了**生存性判据**：缺 S4（情报适应）的系统无法适应环境变化；缺 S5（政策认同）的系统会漂移。我们的产线（pipeline）四角色=简化版 VSM，可对照补缺。

**对操盘系统**：产线团队对照 VSM 五系统审计——S1 运营（writer）/S2 协调（team-lead）/S3 控制（gatekeeper）/S4 情报（雷达）/S5 认同（定位）——缺哪环补哪环。

### ⭐⭐⭐ 被低估 #5：兵棋推演 + 军事红队 → Agent 评估的对抗思维

**映射**：BenchJack（arXiv:2605.12673）实证——**"评估流水线没有内化对抗思维"**：219 个奖励黑客缺陷，WebArena/OSWorld 三迭代内从近 100% 可黑降至 <10%。军事界几百年的兵棋推演+红队（E3/I2）正是这套对抗评估的成熟版。

**为什么被低估**：LLM-as-Judge 在红队分布偏移下退化到随机水平（arXiv:2603.06594）——评估领域需要军事级对抗思维，但主流评估论文仍以"静态基准"为主。利润驱动红队（arXiv:2603.20925）证明**优化过的对手能诱导目标做严格劣势决策**——这就是军事"重心打击"在评估中的应用。

**对操盘系统**：evals 升级为"兵棋推演式评估"——不只测"能不能答对"，要测"被优化对手攻击后是否崩溃"；红队从"三视角自检"升级为"对抗模拟"。

### ⭐⭐⭐ 被低估 #6：OODA 的 Orient=重心 → Context Engineering 的理论根基

**映射**：Boyd 原意——**Orient（判断）是循环的重心**，不是四步之一；Orient 错则全循环错。LLM Agent 的 Orient=上下文窗口（L1）——**Context Engineering 就是工程化 Orient**（ASDLC/superml 2026 已提出）。但产业界仍在"Orient 只是一步"的简化版上。

**为什么被低估**：Boyd 的隐式引导（观察直连行动）对应 agent 的"快路径"（系统1）——当 Orient 已内化（工具定义/系统提示），可跳过显式推理；错误 Orient（污染上下文/幻觉状态）会让快速循环快速走向错误决策——这与"上下文污染"研究（L1）完全同构，但 Boyd 1976 年就预言了。

**对操盘系统**：上下文工程优先级=最高（我们的 Context Engineering 概念卡已是尖刀1）——现在有了军事理论根基：**Orient 是重心，上下文是 Orient 的物质载体**。
