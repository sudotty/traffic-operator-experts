## 一、原理层

### 1.1 传播力乘法模型
**L1**：传播概率 = 社交货币×情绪×实用×触发×故事÷摩擦——五因子相乘，任一为 0 则归零。
**L2**：传播是复制——每个环节都要成立（引子→记忆点→转发动机→场景触发）。
**L3**：社交货币=转发者显得聪明；情绪=高唤醒（惊叹/愤怒/共鸣）；摩擦=理解+转发+风险成本。
**L4**：逐因子打分（0-2），任一项 0 即放弃/补强。2026 校正：AI 引用时代「触发」权重上升——被 AI 检索到本身就是触发。
**L5**：高传播≠高转化；传播力不解释「被 AI 引用」（那是 GEO 模型领域）。
> 人话：内容要火，得让人想分享、记得住、用得着、天天碰得到。锚点：first-principles.md 第一节。

### 1.2 GEO 引用概率模型
**L1**：P(被 AI 引用)=P(检索)×P(选中)×P(归因)，任一弱则整体塌。
**L2**：生成式引擎是「检索→排序→合成」流水线，三步是独立事件。
**L3**：检索环=可爬/可索引/相关（SAGEO Arena：朴素改写伤检索 -9%/-16%/-6%，arXiv:2602.12187）；选中环=答案内引用份额（原「+40%」，Martinez）；归因环=实体清晰署名一致（arXiv:2606.04990）。
**L4**：自测定位最弱环→检索弱修结构/选中弱补结论块/归因弱统一实体名。修复优先于重写（改 5% 内容 +40%，Tian arXiv:2603.09296）。
**L5**：三环皆强不保证稳定（Jaccard 0.34-0.42 日波动，Schulte 2026）；无技术证明对「有机可发现性」有跨平台纵向因果。
> 人话：AI 引用你，要过三关：能搜到你、选了你、还愿意点名你。锚点：Princeton KDD 2024。

### 1.3 信息增益（第一性护城河）
**L1**：内容相对全网已有信息的增量 = 独家数据+一手经验+独特视角+可提取结论——引用潜力系数的底层。
**L2**：AI 引用本质是「择优」——唯一性=被选中概率。
**L3**：三来源——一手数据（我测的）/一手经验（我做的）/独特编排（把已知串成新知）。
**L4**：成文前自问「多少是别人没有的？」≥30% 才动笔；系数：独家 1.5/结构化 1.2/整合 1.0/同质 0.7。
**L5**：信息增益≠冷门——需与搜索意图交叉（评分卡=增益×意图×商业价值）。
> 人话：写别人没有的东西，AI 才会选你。

## 二、机制层

### 2.1 零点击经济
**L1**：搜索点击结构性萎缩，价值从「点击」迁「被引用/被看见」。
**L2**：AI 摘要直接给答案——「点击」环节被系统性消除。
**L3**（2026 硬数据）：68.01% 零点击（2026.1-4，2024 为 60.45%，+7.56pt 十年最快加速）【SparkToro/Similarweb，Fishkin 2026.6】；AIO 出现于 >20% 搜索时 CTR 降近 60%【同上】；每千次搜索仅 276 次点击达开放网络（-22.9%）【同上】；Adobe：AI 引荐流量 YoY +400%，到站转化比非 AI 高约 42%【2026.4】；McKinsey：2028 年 $750B 流经 AI 搜索【2025.8】。
**L4**（Fishkin Zero Click Marketing）：从「抢点击」转「抢被引用」（结论前置/来源/数据）；品牌化（品牌词占搜索约 44%，强品牌胜率 2 倍）；自有资产（邮件/社区/一方数据）；用相关看板替代流量计分板。
**L5**：零点击是均值——品牌词/高购买意图仍高点击；AI Mode 仅 0.34% 但斜率陡。
> 人话：用户搜完不点了——得让 AI 在答案里提到你。锚点：Fishkin《The Click Is Now Optional》2026.6。

### 2.2 Agent 工程四范式
**L1**：prompt → workflow/context → harness → agent-native training 四演进。
**L2**：Agent 质量 = 模型×harness×任务结构×评估——瓶颈不一定在模型（arXiv:2606.20683）。
**L3**：harness 六大职责：观察/上下文/控制/行动/状态/验证；范式升级=问题从模型层移到系统层解决。
**L4**（Karpathy/Willison/Osmani 2025-2026）：Agentic Engineering=编排+监督，人保留架构/规格/验证权（Karpathy 2026.2）；70% 时间问题定义与验证策略，30% 执行（Osmani）；Red/Green TDD、First Run the Tests（Willison）。
**L5**：LangChain 2026.6（N=1,340）：57.3% 已生产，32% 称「质量」是最大障碍（非成本），context 管理是根因；89% 有可观测性但仅 52.4% 跑离线评估→**评估基建仍是最稀缺能力**。
> 人话：工程师的工作从写代码变成「管 AI 干活」——管得好不好决定系统好不好。

### 2.3 Context Engineering
**L1**：设计模型「回答前看到的一切」——填对上下文窗口，非改措辞。
**L2**：输出质量取决于输入上下文的信息配比——缺关键上下文时 prompt 怎么写都没用。
**L3**（概念演化）：Lütke（2025.6.18 提议）→ Karpathy 定义（2025.6.25，~14k 赞）→ Willison 补刀 → Anthropic 官方化（2025.9，Claude Sonnet 4.5）→ LangChain 数据证实（32% 根因）。
**L4**：四策略——①分层缓存（蚂蚁 Ling-3.0-flash 首 token -60~80%）②检索压缩（Context-IR：100K→4K）③时序编排④状态管理。
**L5**：大上下文≠万能——「刚好」的信息（Karpathy）而非「越多」。
> 人话：先保证 AI 该知道的东西它都看到了。锚点：Lütke→Karpathy→Willison→Anthropic（9 天定名史）。

## 三、操作层

### 3.1 三层阅读架构
**L1**：L1 摘要（30 秒独立可读）/L2 信号卡（3 分钟）/L3 深度（按需）。
**L2**：决策者时间成本最高——倒金字塔+分层让读者按需取用。
**L3**：L1 每条带引用号；L2 每卡自包含；L3 只放可检索内容。
**L4**：TL;DR ≤5 条、每条一行含 1 关键数字；信号卡五字段缺一不可。
**L5**：分层≠删信息——专业决策者要求深度时 L3 必须给足。

### 3.2 Share of Visibility
**L1**：多次运行品牌「出现率」——AI 排名是噪声，出现率是信号。
**L2**：LLM 生成是概率性——同 prompt 两次结果可能不同（品牌列表一致率 <1%，加排序约 1/1000）。
**L3**：传统「排名」度量是类别错误——「测概率分布却用确定性指标」；AI 可见度市场 >$100M/年但大多测错。
**L4**：50 次变化运行→出现 22 次=44% 份额；四维变化（run/paraphrase/date/engine）×7-8 次重复起步；报告「占比」非「排名」。
**L5**：出现率不回答转化——需与品牌词/直接流量/收入做相关看板（非归因）。
> 人话：别问「我排第几」，要问「100 次里提我几次」。锚点：Gumshoe 600 志愿者 2,961 次运行。

### 3.3 信号卡五字段
**L1**：每条机会 = 信号/证据/影响/行动/一句话人话。
**L2**：决策损耗最低——扫五字段即完成「要不要做、做什么」判断。
**L3**：信号（发生了什么+日期）→证据（数字+来源+口径+置信度）→影响→行动（P0/P1/P2）→人话（≤20 字）。
**L4**：同构模板强制；置信度标记【事实】/【推断】/【经验判断】。
**L5**：五字段是输出格式，不是思考替代——推理链仍要完整。

### 3.4 三层表达
**L1**：同一内容三层表达——专业（术语+数据+论文）/落地（动作+预算+指标）/通俗（一句话人话）。
**L2**：专业读者阅读是「扫结论→查证据→下指令」三步——三层对应三步。
**L3**：L1 通俗（快速理解）/L2 专业+落地（深挖+执行）/L3 全专业（引用）。
**L4**：每张信号卡强制「一句话人话」——逼作者确认「我真的懂」。
**L5**：三层表达≠稀释专业——通俗是翻译不是降智。

## 四、边界层

### 4.1 GEO 批判综述校正
**L1**：GEO 效果声明必须区分「检索」与「答案内引用份额」两环节；条件效应不得表述为无条件。
**L2**：Martinez 综述（45 项研究，arXiv:2607.14035）：「+40%」=固定上下文内引用份额（词数 19.3→27.2，+41%），≠+40% 曝光/点击/检索概率。
**L3**：证据分级——已检索内容的引用有因果证据；「有机可发现性」跨平台纵向因果无证据；市场 ROI 宣称远超学术证据。
**L4**：引用「+40%」必带条件「固定上下文内、已被检索」；GEO 方案先说检索基建再谈优化。
**L5**：校正≠否定 GEO——「修复优于重写」（Tian）与「结构是安全网」（SAGEO）是综述认可的确定性动作。
> 人话：AI 已经读到你之后的引用份额，不是「更多人搜到你」。别被话术忽悠。

### 4.2 红队三视角
**L1**：交付前三视角攻击自己：挑剔甲方/平台算法/竞争对手。
**L2**：认知偏差只能靠「换立场」破——自我辩护者找不到漏洞。
**L3**：甲方（哪个数据会被挑战）→算法（凭什么被收录/引用）→竞品（抄走后增益还剩什么）。
**L4**：三问逐条回答，任一答不上→返工；与三档预期联用。
**L5**：红队是「减噪」不是「加怯」——去掉无依据的自信，不是把结论都改「可能」。

## 八、融合结论（一套打法）

**总纲**：零点击（68%）+ Agent 生产化（57.3%）+ AI 排名噪声（<1%）三重现实下，内容获客 = **把内容做成「AI 信任且愿意引用的事实源」**，而非「人愿意点击的页面」。

**5 条操作主线**：
1. 检索是前提，结构是安全网（GEO 三环 × SAGEO）
2. 引用份额是目标，出现率是度量（零点击 × SoV）
3. 修复优先于重写，增益优先于完整（Tian × 信息增益）
4. 语境即一切，Context 是 Agent 时代的地基（Context × Agentic Engineering）
5. 三层表达 × 信号卡 = 决策损耗最低（output-spec）
