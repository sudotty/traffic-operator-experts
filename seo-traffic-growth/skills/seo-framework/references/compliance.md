# 合规护栏（广告法 / 版权 / 平台规则）

> 行为化护栏：**不是"禁止写什么"，而是"命中后怎么改"**。输出任何标题/正文前必须过本清单，命中即自动改写并告知用户改动点。

## 一、广告法违禁词库（《广告法》第九条等）

### 绝对化用语（高危，全平台通用）
国家级、最高级、最佳、第一、首个、首选、顶级、顶尖、极致、万能、绝对、永久、无敌、全网最低、史上最强、100%、绝无仅有、空前绝后

### 虚假承诺类（高危）
保证、包过、保分、保本、稳赚、根治、治愈、药到病除、无效退款（无依据时）、 guaranteed 类英文等效表述

### 行业特殊限制
- **金融**：禁止"保本保收益""无风险高回报"，禁止承诺收益率
- **医疗/健康**：禁止宣称治愈率/有效率，禁止患者名义背书（非医疗广告禁止涉及疾病治疗功能）
- **教育**：禁止"保过""保录""提分保证"，禁止利用受益者名义做证明
- **房地产**：禁止"升值承诺""投资回报承诺"，禁止以时间表示距离

## 二、行为化改写规则（命中 → 怎么改）

| 违禁表述 | 合规改写（可证实 + 限定范围） |
|---|---|
| 全网最低价 | 「我们比价了 6 个平台，这款低 15%（截至 2026.7）」 |
| 最好的 SEO 课程 | 「我们服务过的 327 家客户中复购率最高的一门课」 |
| 第一选择 | 「在 XX 细分场景下，被提及次数最多的选项」 |
| 保证有效 | 「按这个 SOP 执行的账号中，80% 在 3 个月内看到品牌词增长」 |
| 彻底治愈 | 直接删除功效表述，改为「用户反馈集中在 XX 改善」并标注为个体案例 |

**改写三原则**：① 绝对 → 相对（加比较范围和样本）；② 承诺 → 概率（给历史数据支撑的比例）；③ 断言 → 体验（改为可验证的用户体验描述并标注个体性）。

## 三、数据与内容引用合规

- **禁止捏造**：用户评价、销量数据、案例数据必须有据可查，没有的标【待核实】
- **引用须标注**：数据来源 + 年份 + 口径（与 benchmarks.md 规则一致）
- **版权边界**：图片须自制/正版图库/获授权；转载内容须获授权并标注来源；引用他人数据图表须注明出处
- **AI 生成声明**：部分平台（公众号、小红书）已要求或建议标注 AI 辅助创作，按平台最新规则执行（涉时效，用前先检索）

## 四、平台规则红线

| 平台 | 红线 |
|---|---|
| 微信/公众号 | 禁止诱导分享/关注话术（"转发朋友圈截图领取"）；标题党（题文不符）处罚；原创声明规范；外链限制 |
| 小红书 | 站外导流处罚（微信/淘宝链接），用"暗线承接"（谐音、合集、简介）；软广需走蒲公英报备 |
| 知乎 | 软文/带货需标注；恶意营销限流 |
| 头条/百家号 | 题文不符、夸大标题降权；医疗金融需资质认证 |

## 五、护栏执行流程（每次输出前必走）

1. 全文扫描违禁词库（含变体、谐音、英文等效表述）
2. 命中 → 按"改写三原则"自动改写 → 在交付物末尾列出「合规改动清单」（原文 → 改后 → 依据条款）
3. 行业敏感领域（金融/医疗/教育/房产）→ 额外检查行业特殊限制，无法确认合规时明确提示"建议法务复核"
4. **优先级**：合规 > 真实 > 用户目标 > 网感风格。当"冲突感标题"与合规冲突时，合规赢，用"事实反差"替代"绝对化夸大"来保住张力
