# 专业决策者输出规格 v2（OODA 收敛版）

> 面向：重视数据 / 重视 AI / 重视学术化 / 重视海外资讯的专业决策者（AI PM、增长负责人、ToB 售前、研究者）。
> 目标：**决策损耗最低**——不是信息更全，而是每个字都降低读者做决定的时间成本。
> 本规格是 SKILL.md 规则 0（受众视角）的可执行细则，所有雷达/方案/报告类产出默认遵守。

## 〇、总原则：三条铁律

1. **倒金字塔**：每个模块第一句 = 结论；细节往下沉。读者只看前 3 行就能做出「要不要深读」的判断。
2. **三选一**：每句话必须属于「数据 / 结论 / 行动」之一，否则是噪声，删除。
3. **同构模板**：所有雷达/方案用同一骨架（见 §1），形成肌肉记忆，读者扫一眼就知道去哪找什么。

## 一、三层阅读架构（可读性）

任何雷达/报告分三层，按需取用：

```
┌─ L1 摘要层（30 秒）────────────────────────────┐
│ TL;DR：3-5 条决策级结论，每条一行，含 1 个关键数字   │
├─ L2 证据层（3 分钟）────────────────────────────┤
│ 信号卡 × N（见 §3）：结论 + 证据 + 置信度 + 影响    │
├─ L3 深度层（按需）──────────────────────────────┤
│ 概念定义卡 / 方法论 / 原始论文 / 完整推导            │
└──────────────────────────────────────────────┘
```

规则：
- **L1 必须独立可读**：不看 L2/L3 也能完成决策；L1 内每条结论自带出处引用号。
- **L2 每张信号卡自包含**：不依赖上下文，可单独转发。
- **L3 只放「可检索」内容**：论文 arXiv 号、报告名+年份、方法口径——不写回忆式论述。

## 二、信噪比规则（去噪清单，交付前逐条自查）

| # | 噪声类型 | 处理 |
|---|---|---|
| N1 | 重复数据 | 每个数字**只出现一次**，他处用交叉引用（「见 A3」） |
| N2 | 行业共识复述 | 「AI 很重要」「内容为王」类零增量句 → 删除 |
| N3 | 未校准猜测 | 没数据的推断必须标【推断】+ 逻辑链，否则删除 |
| N4 | 无关热点罗列 | 与决策坐标无关的热点不写；写就说明「为什么影响你」 |
| N5 | 模糊程度词 | 「显著/大幅/明显」→ 换成具体数字；给不出数字就删 |
| N6 | 装饰性过渡句 | 「值得注意的是」「综上所述」→ 删除，直接给结论 |
| N7 | 口径混排 | 不同来源/方法的数字不得直接并排比较，必须注明各自口径 |
| N8 | 无行动结论 | 每条结论必须能回答「So What」，否则降级为背景信息并注明 |

## 三、信号卡格式（信息效率 × 接收效率）

每条机会/发现用统一卡片，**五字段缺一不可**：

```
【信号】一句话：发生了什么（含日期）
【证据】数字 + 来源（年份/口径）+ 置信度标记【事实】/【推断】/【经验判断】
【影响】对目标决策坐标（获客/转化/成本）的具体含义
【行动】P0/P1/P2 + 具体动作（做什么形态、给谁看）
【一句话人话】≤20 字大白话翻译（专业化×通俗化的接缝）
```

示例：
```
【信号】DeepSeek 重启 5000 亿估值融资（8/5）
【证据】投前估值 5000 亿元，较首轮投后 +43%（《财经》8/5，交易人士口径）【事实】
【影响】国产模型 API 涨价预期强化 → 推理成本类内容被搜索概率上升
【行动】P1：做《国产模型 API TCO 对比表》，面向采购决策人群
【一句话人话】DeepSeek 更贵了也更值钱了，写篇"谁家模型最省钱"稳吃搜索。
```

## 四、表达规则（语言层）

1. **数字优先**：`+32%` 代替「显著提升」；`41% 12月内回本` 代替「多数能回本」。
2. **主动语态**：`我们做 X` 而非 `X 应当被做`。
3. **术语首次出现给定义**：`Context Engineering（上下文工程，指选择性构造模型看到的上下文）`，之后直接用英文。
4. **结论前置**：段落首句给结论，论证后置。
5. **表格 > 段落**：对比/列表/评分用表格，不用长段落；表格每行 ≤12 字结论性描述。
6. **引用格式统一**：`来源（年份，口径）` 内联标注；论文带 arXiv 号。

## 五、思考框架（So What / Now What / What If）

每份产出末尾必须回答三问，缺一不可：

```
【So What】这些信号组合起来意味着什么？（跨信号合成，不是逐条复述）
【Now What】本周具体做什么？（P0/P1/P2 行动项，含形态与受众）
【What If】若某假设翻转（AI 覆盖再升 20% / 平台改规则），哪个环节先死？（二阶风险）
```

## 六、三层表达规范（专业化 × 落地 × 通俗化）

| 层 | 内容 | 示例 |
|---|---|---|
| 专业层 | 术语+数据+论文引用 | 「SAGEO Arena 实测朴素正文优化检索 -16%（arXiv:2602.12187）」 |
| 落地层 | 产业建议（动作/预算/指标） | 「P0 动作：先修结构（Schema/标题层级），预算≈0，指标=AI 引用率周环比」 |
| 通俗层 | 一句话人话 | 「别急着重写文章，先把标题和段落结构理清楚，AI 才读得懂你」 |

规则：**L1 摘要层用通俗化**（决策者快速理解），**L2 证据层用专业+落地**（决策者深挖+执行），**L3 深度层全专业**（研究者引用）。

## 七、输出结构模板（同构骨架，所有雷达/方案复用）

```
# <标题> · 专业决策者版（<日期>）

## TL;DR（30 秒）
- <结论1>（引用号①）
- <结论2>（引用号②）

## 信号卡（L2 证据层）
### ① <信号名>
（五字段信号卡格式）

## 概念定义卡（L3，仅当涉及新术语）
| 概念 | 定义 | 案例 | 锚点 |

## So What / Now What / What If
（三问）

## 数据纪律声明
（来源占比 / 口径说明 / 【待核实】清单）
```

## 八、轻轨/全轨分流（防止规格过载）

- **轻轨**（改标题/润色/单点问答）：只执行 §4 表达规则 + 合规扫描，不套全规格。
- **全轨**（雷达/选题/策略/SOP）：完整执行 §1-§7。
- 判断不了按全轨，但先自问：「用户要决策还是执行？」执行类给全规格是流程过载。

## 九、验证标准（交付前自查）

- [ ] L1 摘要独立可读，含关键数字与引用号
- [ ] 无 N1-N8 噪声（逐条过）
- [ ] 每个【事实】有 来源+年份+口径；【推断】有逻辑链
- [ ] 每张信号卡五字段齐全，含「一句话人话」
- [ ] So What / Now What / What If 三问齐备
- [ ] 表格优先于段落，术语首现定义
