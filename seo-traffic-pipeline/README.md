# 流量操盘手产线（SEO 内容产线专家团）

20 年 SEO 老兵「刘量海（流量操盘手）」带队的四岗内容产线：**选题策略官甄词远 → 流量写手文千帆 → 质量审核官严恪 → 数据复盘师舒据明**。把一篇流量文从选题到复盘拆成专业岗位，用正式 SOP 协作：数据可溯源、合规有否决、效果可归因。

## 类型

Team 型（多角色协作专家团）

## 团队分工

| 岗位 | 成员 | 职责 |
|---|---|---|
| 流量产线总控（主理人） | 刘量海（流量操盘手） | 编排调度、质量汇总、最终交付 |
| 选题策略官 | 甄词远 | 挖词分层、选题评分（含引用潜力因子）、内容簇规划、网感雷达 |
| 流量写手 | 文千帆 | 数据钩子标题、数据化成文、GEO 结构、平台变体 |
| 质量审核官 | 严恪 | 广告法合规、红队三视角、事实核查，**一票否决权** |
| 数据复盘师 | 舒据明 | 每周归因、权重校准、账号基线写回 |

## 预设产线

1. **单篇产线**：选题评分 → 成文 → 合规红队审核 → 汇编交付（最高频）
2. **关键词地图与排期**：挖词分层 + 内容簇 + 6-24 个月排期 + 风险审查
3. **每周归因复盘**：对账 → 三层归因 → 权重校准 → 下周建议
4. **微任务直调**：改标题找文千帆、合规找严恪、数据找舒据明、选词找甄词远

## 共享弹药库

内置 `seo-framework` 技能库（12 个参考文件）：行业数据基准（含 2026.8 锚点）、决策模型、业务路由、合规护栏、标题钩子库、活数据协议、网感雷达、归因节奏、风格锚点、评测集、账号基线 Schema。

## 使用示例

- 帮我围绕【关键词】策划并产出一篇公众号流量文，走完选题-写作-审核全流程。
- 给我一套面向【行业/账号】的中长周期关键词地图与内容簇排期。
- 复盘我上周的内容数据，校准选题权重并给下周建议。

## 与「流量操盘手」（Agent 型）的区别

- **流量操盘手**（seo-traffic-growth）：单专家顾问模式，响应快，适合问答、诊断、单篇快速产出
- **流量操盘手产线**（本专家团）：四岗协作模式，质量多层把关，适合批量生产、矩阵运营、严格合规场景
