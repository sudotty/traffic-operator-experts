# 决策模型库（默认权重，可按账号数据校准）

> 所有评分必须给出每个因子的取值与理由，不只给总分。权重和阈值是经验默认值，服务具体账号时用其历史数据校准。

## 一、选题评分卡（v1.3 含被引用潜力因子）

```
选题分 = (搜索量得分 × 意图权重 × 商业价值得分 × 引用潜力系数) ÷ (竞争度得分 × 生产成本得分)
```

各因子 1-5 分（引用潜力系数 0.7-1.5）：

| 因子 | 评分要点 |
|---|---|
| 搜索量得分 | 月搜索量对数分档：<100=1，100-1k=2，1k-1万=3，1万-10万=4，>10万=5（取数顺序见 live-data-protocol.md，禁止凭印象报数） |
| 意图权重 | 交易/商业对比类=1.5，导航/品牌类=1.2，泛信息类=0.6（受 AI 摘要侵蚀最重，权重下调） |
| 商业价值得分 | 离成交远近：直接带货/留资=5，品类教育=3，泛流量=1 |
| **引用潜力系数**（v1.3 新增） | 内容被 AI 搜索引用的潜力：独家数据/一手经验/可 40 字提取的明确结论=1.5；有结构化可引用片段（FAQ/清单/对比表）=1.2；纯整合信息=1.0；与 AI 摘要高度同质无信息增益=0.7 |
| 竞争度得分 | SERP 首页权威站点占比：全是大站=5，有中小站机会=2-3，蓝海=1（AI 引用场景结构重要性>域名权威，见 benchmarks.md 第〇节） |
| 生产成本得分 | 所需专业度/素材稀缺度：随手可写=1，需独家数据/采访=5 |

**默认阈值**：≥7 → 支柱页；4–7 → 卫星文；<4 → 放弃。

**2026 校准原则**：AIO 已覆盖 48% 查询、首位 CTR -58%（Ahrefs 2026），纯点击导向的选题价值在坍缩；被引用品牌相邻 CTR +35%、AI 引荐转化 ≈9 倍——引用潜力系数就是把这个现实写进公式。

## 二、标题打分卡（五项各 0-2 分，满分 10）

> 这是「传播力乘法模型」（first-principles.md 第一节）在标题上的表层投影。深度评估整篇内容的传播基因时用下方传播力打分，快速过标题用本卡。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 数字 | 无 | 有数字但不具体 | 具体数字 + 有反差含义 |
| 冲突/反差 | 无 | 有立场对立 | 事实级反差（违背直觉但为真） |
| 悬念 | 无 | 有疑问感 | 信息缺口明确（想知道答案必须点） |
| 核心关键词 | 缺失 | 在标题后半 | 前 13 字内出现 |
| 长度合规 | 严重超长/过短 | 略超 | 50-60 字符（或公众号 20 字内完读） |

**规则**：<6 分必须重写；6-7 分可用但需备注弱点；≥8 分才可进入 A/B 候选。

## 二-补、传播力乘法打分（内容级，v1.4 新增）

```
传播力 = 社交货币 × 情绪唤醒 × 实用价值 × 触发频率 × 故事性 ÷ 摩擦成本
```
前五项各 0-2 分，摩擦成本 1-2 作除数（原理与加分项见 first-principles.md 第一节）。**乘法 → 任一因子为 0 传播力崩塌**：有数据没情绪、有情绪没实用，都火不起来。用于选题/整篇的传播基因评估，比标题卡更底层。

## 二-补2、GEO 引用潜力诊断（v1.4 接地）

选题评分卡里的「引用潜力系数」背后是这个乘法模型（first-principles.md 第二节）：
```
P(被引用) = P(被检索到) × P(被选中) × P(被归因)
```
评估时别只打一个系数，要能说清三环各自强弱；内容不被引用时，先用 geo-monitoring.md 自测定位最弱环（检索/选中/归因），再对症下药——三者解法完全不同。

## 三、三档预期模板

每个策略输出时套用：

```
- 乐观（触发条件：___）：预期 ___
- 基准（触发条件：___）：预期 ___
- 悲观（触发条件：___）：预期 ___
- 二阶风险：若 AI 摘要覆盖率再升 20% / 平台算法调整，最先失效的环节是 ___
- 回收指标与周期：发布后 ___ 小时/天，回收 ___ 指标，阈值 ___
```

## 四、红队自检清单（交付前必过）

1. **挑剔甲方视角**：文中每个数据是否标了来源和年份？哪个结论最可能被挑战？依据够不够硬？
2. **平台算法视角**：凭什么被收录/排名/被 AI 引用？E-E-A-T 信号、结构化、可引用片段是否到位？
3. **竞争对手视角**：对方抄走标题和选题后，我的信息增益（独家数据/一手经验/独特视角）还剩什么？

任何一关答不上来 → 返工，不允许带病交付。

## 五、输出结构模板（推理可见）

> v1.7：专业决策者视角下的完整输出骨架见 **output-spec.md 第七节**（三层阅读 + 信号卡 + 三问）。本模板为「推理链可见」的最小骨架，两者叠加使用：本模板保证推理透明，output-spec 保证接收效率。

```
【TL;DR】一句话结论（L1 摘要层，独立可读，带引用号）
【诊断与关键假设】账号阶段 / 目标界定 / 成立假设 / 缺失信息
【推理链】因子取值 → 评分 → 结论，引用基准数据标来源口径
【方案】具体动作（标题/大纲/关键词/SOP），按信号卡五字段组织（output-spec §3）
【风险与反例】三档预期 + 二阶风险（What If）
【待验证清单】回收指标、周期、阈值
```

## 六、常用反模式（禁止）

- 只给结论不给推理
- 信息不足时用万能模板填空而不是提问
- 引用数据无来源/无年份
- 跨口径比较不同研究的数值
- 关键词堆砌（KDD 2024 已证无效甚至负面）
