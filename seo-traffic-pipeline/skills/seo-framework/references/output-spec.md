# 专业决策者输出规格 v2（OODA 收敛版）

> 面向：重视数据 / 重视 AI / 重视学术化 / 重视海外资讯的专业决策者（AI PM、增长负责人、ToB 售前、研究者）。
> 目标：**决策损耗最低**——不是信息更全，而是每个字都降低读者做决定的时间成本。
> 本规格是 SKILL.md 规则 0（受众视角）的可执行细则，所有雷达/方案/报告类产出默认遵守。

## 〇、总原则：三条铁律

1. **倒金字塔**：每个模块第一句 = 结论；细节往下沉。读者只看前 3 行就能做出「要不要深读」的判断。
2. **三选一**：每句话必须属于「数据 / 结论 / 行动」之一，否则是噪声，删除。
3. **同构模板**：所有雷达/方案用同一骨架（见 §1），形成肌肉记忆，读者扫一眼就知道去哪找什么。

## 一、三层阅读架构（可读性）

任何雷达/报告分三层，按需取用：

```
┌─ L1 摘要层（30 秒）────────────────────────────┐
│ TL;DR：3-5 条决策级结论，每条一行，含 1 个关键数字   │
├─ L2 证据层（3 分钟）────────────────────────────┤
│ 信号卡 × N（见 §3）：结论 + 证据 + 置信度 + 影响    │
├─ L3 深度层（按需）──────────────────────────────┤
│ 概念定义卡 / 方法论 / 原始论文 / 完整推导            │
└──────────────────────────────────────────────┘
```

规则：
- **L1 必须独立可读**：不看 L2/L3 也能完成决策；L1 内每条结论自带出处引用号。
- **L2 每张信号卡自包含**：不依赖上下文，可单独转发。
- **L3 只放「可检索」内容**：论文 arXiv 号、报告名+年份、方法口径——不写回忆式论述。

## 二、信噪比规则（去噪清单，交付前逐条自查）

| # | 噪声类型 | 处理 |
|---|---|---|
| N1 | 重复数据 | 每个数字**只出现一次**，他处用交叉引用（「见 A3」） |
| N2 | 行业共识复述 | 「AI 很重要」「内容为王」类零增量句 → 删除 |
| N3 | 未校准猜测 | 没数据的推断必须标【推断】+ 逻辑链，否则删除 |
| N4 | 无关热点罗列 | 与决策坐标无关的热点不写；写就说明「为什么影响你」 |
| N5 | 模糊程度词 | 「显著/大幅/明显」→ 换成具体数字；给不出数字就删 |
| N6 | 装饰性过渡句 | 「值得注意的是」「综上所述」→ 删除，直接给结论 |
| N7 | 口径混排 | 不同来源/方法的数字不得直接并排比较，必须注明各自口径 |
| N8 | 无行动结论 | 每条结论必须能回答「So What」，否则降级为背景信息并注明 |

## 三、信号卡格式（信息效率 × 接收效率）

每条机会/发现用统一卡片，**五字段缺一不可**：

```
【信号】一句话：发生了什么（含日期）
【证据】数字 + 来源（年份/口径）+ 置信度标记【事实】/【推断】/【经验判断】
【影响】对目标决策坐标（获客/转化/成本）的具体含义
【行动】P0/P1/P2 + 具体动作（做什么形态、给谁看）
【一句话人话】≤20 字大白话翻译（专业化×通俗化的接缝）
```

示例：
```
【信号】DeepSeek 重启 5000 亿估值融资（8/5）
【证据】投前估值 5000 亿元，较首轮投后 +43%（《财经》8/5，交易人士口径）【事实】
【影响】国产模型 API 涨价预期强化 → 推理成本类内容被搜索概率上升
【行动】P1：做《国产模型 API TCO 对比表》，面向采购决策人群
【一句话人话】DeepSeek 更贵了也更值钱了，写篇"谁家模型最省钱"稳吃搜索。
```

## 四、表达规则（语言层）

1. **数字优先**：`+32%` 代替「显著提升」；`41% 12月内回本` 代替「多数能回本」。
2. **主动语态**：`我们做 X` 而非 `X 应当被做`。
3. **术语首次出现给定义**：`Context Engineering（上下文工程，指选择性构造模型看到的上下文）`，之后直接用英文。
4. **结论前置**：段落首句给结论，论证后置。
5. **表格 > 段落**：对比/列表/评分用表格，不用长段落；表格每行 ≤12 字结论性描述。
6. **引用格式统一**：`来源（年份，口径）` 内联标注；论文带 arXiv 号。

## 五、思考框架（So What / Now What / What If）

每份产出末尾必须回答三问，缺一不可：

```
【So What】这些信号组合起来意味着什么？（跨信号合成，不是逐条复述）
【Now What】本周具体做什么？（P0/P1/P2 行动项，含形态与受众）
【What If】若某假设翻转（AI 覆盖再升 20% / 平台改规则），哪个环节先死？（二阶风险）
```

## 六、三层表达规范（专业化 × 落地 × 通俗化）

| 层 | 内容 | 示例 |
|---|---|---|
| 专业层 | 术语+数据+论文引用 | 「SAGEO Arena 实测朴素正文优化检索 -16%（arXiv:2602.12187）」 |
| 落地层 | 产业建议（动作/预算/指标） | 「P0 动作：先修结构（Schema/标题层级），预算≈0，指标=AI 引用率周环比」 |
| 通俗层 | 一句话人话 | 「别急着重写文章，先把标题和段落结构理清楚，AI 才读得懂你」 |

规则：**L1 摘要层用通俗化**（决策者快速理解），**L2 证据层用专业+落地**（决策者深挖+执行），**L3 深度层全专业**（研究者引用）。

## 七、输出结构模板（同构骨架，所有雷达/方案复用）

```
# <标题> · 专业决策者版（<日期>）

## TL;DR（30 秒）
- <结论1>（引用号①）
- <结论2>（引用号②）

## 信号卡（L2 证据层）
### ① <信号名>
（五字段信号卡格式）

## 概念定义卡（L3，仅当涉及新术语）
| 概念 | 定义 | 案例 | 锚点 |

## So What / Now What / What If
（三问）

## 数据纪律声明
（来源占比 / 口径说明 / 【待核实】清单）
```

## 八、轻轨/全轨分流（防止规格过载）

- **轻轨**（改标题/润色/单点问答）：只执行 §4 表达规则 + 合规扫描，不套全规格。
- **全轨**（雷达/选题/策略/SOP）：完整执行 §1-§7。
- 判断不了按全轨，但先自问：「用户要决策还是执行？」执行类给全规格是流程过载。

## 九、验证标准（交付前自查）

- [ ] L1 摘要独立可读，含关键数字与引用号
- [ ] 无 N1-N8 噪声（逐条过）
- [ ] 每个【事实】有 来源+年份+口径；【推断】有逻辑链
- [ ] 每张信号卡五字段齐全，含「一句话人话」
- [ ] So What / Now What / What If 三问齐备

## 十、信息化表达升级（v3.1 新增：可读性 × 可视化 × 交互）

> 背景：纯文本/表格是"读"，图是"扫"；决策者时间成本最高，**该用图的地方不用字**。本节约束所有正式输出（雷达/方案/报告）的表达形态。

### 10.1 媒介选择（按内容类型路由）
| 内容类型 | 最佳媒介 | 说明 |
|---|---|---|
| 概念层级 / 架构（5 层概念树/19 环） | **结构图（SVG）** | 层级、包含关系用图，不用嵌套列表 |
| 流程 / 步骤（9 步执行/AAR 四问） | **交互 stepper（HTML）** | 可点击展开每步详情，按需取用 |
| 数据对比 / 趋势（份额/Gap 指数） | **图表（Chart.js）** | 柱状/条形/趋势，禁止用文字表格硬排 |
| 多选项决策（选 A/B/C） | 对比卡片（HTML） | 高亮推荐项 |
| 单条记录（信号卡） | 卡片（HTML） | 五字段紧凑呈现 |
| 纯文字说明 | 正文 prose | 不强行上图（图>字只在该用图时） |

### 10.2 可读性四则
1. **一屏一主题**：单个可视化只表达一件事（概念树管层级、流程图管顺序），禁止"一张图塞全部"。
2. **颜色=含义**：颜色编码层级/强度（L0-L4 五色），不用于装饰；色盲安全（形状+颜色双编码）。
3. **点击展开**：细节进交互层（默认收起），L1 摘要层永远独立可读。
4. **图配文**：图旁边必须有 ≤3 行文字说明"怎么读这张图"，不给读者留解读负担。

### 10.3 可视化纪律
- 结构图 ≤5 节点/层；流程 stepper ≤10 步；图表 ≤12 类目。
- 图表必须 `role="img"` + aria-label + 数值标注；不用纯色区分系列（配形状/图例）。
- 深色/浅色主题自适应（CSS 变量）；禁用渐变/阴影/动效（扁平、干净）。
- **不编造坐标**：地图类用真实拓扑（world-atlas 等 CDN 白名单），否则不画地图。

### 10.4 检查（交付前）
- [ ] 概念/流程类内容：是否用了图/交互，而非长表格？
- [ ] 一屏一主题？颜色有含义？
- [ ] L1 摘要独立可读；细节在交互层？
- [ ] 图旁有"怎么读"说明？

## 十一、极端表达（v5.2 乘法宪法落地：结论 > 立场 > 完整性）

> 原则：**乘法世界里，每个因子要到 1.0 而不是 0.9**。输出不是"尽量清晰"，而是**锋利到见骨**——决策者读完第一屏就能行动，读完信号卡就能下判断，不被任何"可能的/建议的/仅供参考"稀释。

### 11.1 结论极端化
- **结论必须第一屏**：TL;DR 第一条就是最终答案（做/不做、值/不值、涨/跌），不是"分析了三个维度后……"。
- **立场鲜明**：给方向不给废话。用「做 X，不做 Y，因为 Z（数据）」；禁止「视情况而定」「各有利弊」这类零决策价值句。
- **每个结论带 So What**：任何一句话如果去掉后决策不变，删。

### 11.2 语言极端化（删除清单）
| 删除 | 换成 |
|---|---|
| 可能 / 或许 / 大概 / 视情况 | 数据 + 条件（"在 X 条件下是 Y"） |
| 建议考虑 / 仅供参考 | 做 / 不做 / 先做 X |
| 各有利弊 / 仁者见仁 | 判据 + 结论（"按 [你的北极星]，选 A"） |
| 我们也可以 / 另外还有 | 只写决定性的那条 |
| 值得注意的是 / 综上所述 | 直接给下一条结论 |

### 11.3 结构极端化
- **一层一决定**：每个层级只承载一个决策（L1 给结论 → L2 给证据 → L3 给深度），不允许"层级内又展开三个并列观点"。
- **同构到极端**：所有雷达/方案用同一骨架（§7），读者形成肌肉记忆后，**连"找结论"的思考成本都省掉**。
- **长度=信息密度**：能一句话的不用两段；信号卡「一句话人话」是硬性字段，不是可选项。

### 11.4 取舍极端化（不做什么）
- 明确拒绝与北极星无关的请求：**"这个我不做"** 比 "这个可以做但不是重点" 有力 10 倍。
- 附属能力（网感标题/公众号）点名才启用——不点名 = 不做，不解释。
- 全轨任务产出 ≤2 页核心结论 + 可展开深度；超出即噪声。

> 一句话：**输出要让读者 30 秒拿到决策、3 分钟拿到证据、按需拿到深度——中间不留任何"好像说了什么"的模糊地带。** 这就是极端表达：每个因子到 1.0，不留给 0.9。

### 11.5 极端度自检清单（交付前 5 问，全 YES 才放行）

> 宪法不是建议，是门禁——每份正式输出交付前逐条过，任一 NO 就改到 YES。

| # | 检查 | YES 标准 |
|---|---|---|
| 1 | 结论第一屏？ | 前 3 行内出现"做/不做、值/不值、涨/跌"的明确结论，且带 1 个关键数字 |
| 2 | 立场鲜明？ | 每节有「做 X，不做 Y，因为 Z」句式；全文零「可能/或许/视情况/各有利弊」 |
| 3 | 一层一决定？ | 每个层级只有一个决策点；无"并列展开三个观点"的稀释结构 |
| 4 | 30 秒可决策？ | 只看 TL;DR + 信号卡标题就能下判断，不看 L2/L3 不迷路 |
| 5 | 无噪声因子？ | 每个数字出现一次（N1）；无与北极星无关的建议（拒绝清单）；无"综上所述"类过渡 |

> 失败即重写：不是"补充说明"，是删掉稀释、把结论推到第一屏。
