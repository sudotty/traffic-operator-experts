# 每周归因节奏（数据回收 → 归因 → 写回基线）

> 解决问题：三档预期给了却没人对账，"越用越准"就是口号。本文件定义固定的每周归因仪式，把效果闭环真正跑起来。

## 一、节奏设定

- **频率**：每周一次（建议周一，复盘上周）
- **时长**：10-15 分钟对话
- **触发**：可由用户主动发起，或由定时任务提醒（已配置每周一 09:00 的 automation）
- **输入**：用户粘贴上周各平台数据（字段见 live-data-protocol.md 第二节）

## 一-补、AAR 复盘框架（v2.3 军事方法论注入，替代纯归因）

> 每周归因 = 军事 AAR（After Action Review）的流量操盘版。AAR 四问：**①预期是什么？②实际发生了什么？③为什么有差距？④下次怎么改进？**（源于 1970s 以色列装甲兵，美军制度化）。与三层归因结合：AAR 的「差距」= 三层归因的「哪层出问题」；AAR 的「改进」= 归因后的「权重校准 + 下周行动」。

```
【AAR 四问】
① 预期：本周各篇三档预期（乐观/基准/悲观）
② 实际：实际数据落在哪档
③ 差距归因：选题层/表达层/环境层（哪层造成差距）
④ 改进：具体动作（下次选题/标题/结构怎么调——落到"下次怎么做"，非"下次更努力"）
```

**AAR 纪律**：不追责（追责=掩盖真相）；改进必须可验证（否则是仪式）；差距归因要落到具体层。

## 二、归因对话模板

### 第 1 步：数据对账（对照三档预期）
```
| 内容 | 发布日 | 预期(乐观/基准/悲观) | 实际 | 落在哪档 |
|---|---|---|---|---|
| 标题A | 8.3 | 打开率 6%/4%/2% | 5.2% | 基准偏乐观 |
```
没对账的预期 = 没有预期。每篇都问：落在哪档？为什么？

### 第 2 步：归因分析（三层归因）
1. **选题层**：是选题分预测准了，还是市场反应偏离？偏离方向说明哪个因子权重错了？
2. **表达层**：标题/钩子/开头哪个环节漏斗掉得最多？（打开率低=标题问题；完读低=结构问题；分享低=情绪/价值密度问题）
3. **环境层**：平台算法、AIO 覆盖、竞品动作有没有变化？（区分"我做错了"和"环境变了"）

### 第 3 步：校准与写回
- 权重调整：如连续 3 周泛信息词表现好于预期 → 意图权重上调，写入 account-profile-schema 的 `verified_weights`，并在对话中显式说明调整
- 模式沉淀：带来异常值的标题/钩子模式 → 写入 `validated_title_patterns` 和 style-anchors.md
- 证伪声明：被数据推翻的旧结论，明说"上次说 X，数据 Y 证伪了，已修正"
- 下周行动：基于归因给出下周选题/排期建议（1-3 条，不贪多）

## 三、归因输出结构（固定）

```
【本周对账】预期 vs 实际表
【异常值】表现最好/最差各一篇，差异在哪
【归因】选题层/表达层/环境层各一句话结论
【校准动作】权重调整 + 基线写回清单（改了哪些字段）
【下周建议】1-3 条可执行动作
```

## 四、纪律

1. **没有数据就不做归因**：用户没提供数据时，给数据收集清单（live-data-protocol.md），不凭空归因。
2. **单篇不下结论**：样本量不足时标注"单篇波动，累计 3 篇再判"。
3. **归因要落到动作**：每次归因必须产出至少一个"下周可执行的改变"，否则就是复盘表演。
4. **北极星对齐**：归因指标优先级 = AI 引用率/品牌词增量 > 转化（加微/留资） > 打开率/完读率。阅读量只是过程指标。
