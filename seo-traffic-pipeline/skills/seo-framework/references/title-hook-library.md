# 标题与钩子库（细节手册）

> MD 只引用本库，不内嵌细节。所有标题产出后必须过 decision-models.md 的标题打分卡（≥6 分）+ compliance.md 的合规自查。

## 一、标题公式与变体

主公式：`[数字] + [冲突/反差] + [悬念] + [核心关键词]`

常用变体句式：
1. 「做了 X 年 Y，我终于承认 Z 根本不值得做」（资历 + 反共识）
2. 「实测 N 款 X，得分最高的反而最便宜」（数字 + 反差 + 悬念）
3. 「X 的 3 个真相，第 2 个 90% 的人搞反了」（数字 + 悬念）
4. 「别再乱写 X 了：数据说有效的只有这 2 类」（否定式 + 数据权威）
5. 「X 正在杀死 Y：一组被低估的数据」（冲突 + 时代焦虑）
6. 「我复盘了 N 篇 10w+，发现标题都有这 4 个特征」（复盘体 + 清单）
7. 「X 岁转行做 Y，第一年我踩过的 5 个坑」（身份代入 + 损失厌恶）
8. 「为什么你的 X 没流量？不是内容问题，是坐标错了」（归因反转 + 悬念）

## 二、数据钩子类型（开头 3 行必用一个）

| 钩子类型 | 句式 | 示例 |
|---|---|---|
| 对比钩 | A 和 B 的悬殊差距 | 「同样 2000 字，3 款工具可读性差 41%」 |
| 反常钩 | 违背直觉的真数据 | 「流量最高的那篇，恰是我写得最快的」 |
| 身份钩 | 精准锁定一类人 | 「做公众号第 4 个月还没 500 粉的人，问题都出在同一点」 |
| 损失钩 | 损失厌恶 | 「这个错误让我前 6 个月的内容全部白写」 |
| 时间钩 | 时间维度反差 | 「7 天前这个词还没人搜，今天已经抢不到位置」 |

## 三、网感化表达规则

- 短句优先：单句 ≤25 字，段落 ≤3 行，多用断行
- 口语化：用"说白了""你猜怎么着""问题来了"，但每篇 ≤3 次
- emoji：公众号 ≤5 个/篇；小红书可到 8-10 个；知乎/官网不用
- 冲突来自**事实反差**，不是情绪夸大——每条冲突后面必须跟一个可溯源数据
- 突兀 = 结构上的意外（先给结论再讲故事 / 先抛反共识再论证），不是逻辑断裂

## 四、平台字数速查

| 平台 | 标题 | 正文 |
|---|---|---|
| 公众号 | ≤20 字（订阅号列表完整显示） | 1500-3000 字 |
| 小红书 | ≤20 字（含 emoji） | 500-1000 字，清单体 |
| 知乎 | 问题式，≤30 字 | 结论先行，2000 字+ |
| 官网 | 50-60 字符（SERP 不截断） | 支柱页 2500 字+，卫星文 1200 字+ |
