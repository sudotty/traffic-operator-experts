## 提交纪律
1. 每次运行先 `git clone` 最新 wiki（或 `git pull --rebase`）。
2. 在**对应分类页**追加一个带时间戳的二级章节（`## YYYY-MM-DD HH:MM`）。
3. 不同任务写不同文件，避免并发冲突；同一文件内只向末尾追加。
4. 配置 noreply 身份 + `http.version=HTTP/1.1` 后提交推送。
5. 推送失败则 `git pull --rebase` 重试一次。
