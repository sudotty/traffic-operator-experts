## 概念树（全部方法论 → 5 层）

```

│
L1 原理（为什么）：传播力乘法 × GEO 概率(检索·选中·归因) × 信息增益
│
L2 战略法则（打什么仗）：攻虚不攻坚 · 先固垒再出击 · 我专敌分 · 护城河=持续挖沟 · 正奇相生
│

│
L4 交付规格（给人看）：信号卡五字段 · 三层阅读 · 三层表达 · N1-N8 去噪
│

```

## 9 步执行流程（全轨任务 = 走这 9 步）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 | 定目标：北极星（引用率>品牌词>转化>打开率） | 量化目标 |
| 2 | 判状态：账号五态（冷启动/验证/成长/稳定/衰退） | 状态标签 |
| 3 | 看情报：PIR 3-5 条 + 海外信源 80%（多源交叉） | 情报清单 |
| 4 | 选战场：选题评分卡（竞争度=雄牝城，攻虚不攻坚） | 选题+评分 |
| 5 | 定打法：三档预期 + 二阶风险（"哪环先死"） | 预期表 |
| 6 | 执行：产线 8 环（定位→挖词→内容簇→钩子→成文→校验→分发→回流） | 内容+发布 |
| 7 | 验证：红队三视角 + GEO 三环自测（多引擎 7-8 次） | 验证报告 |
| 8 | 复盘：AAR 四问（预期→实际→差距→改进） | 改进动作 |
| 9 | 进化：经验四步（记录→归因→泛化→沉淀）→ 有效才入 SKILL | 版本增量 |

> 失败分支：验证不过 → REPAIR（先修后写，最小改动 ≤10%）；每任务留 TRACE（≤15 行）。

## 铁律速查（8 条）

1. 合规永远赢：`合规 > 真实 > 用户目标 > 网感风格`。
2. 引用必带来源：数据=来源+年份+口径；库外标【待核实】；时效先检索。
3. 不跨口径比数：会话面板≠关键词快照≠曝光日志。
4. 海外为主：论断 80% 引海外一手源（arXiv/Gartner/SE Ranking/PH）；论文带 arXiv 号。
5. GEO 话术校正：「+40%」必须加"固定上下文内"条件（批判综述关）。
6. 评分可见：因子取值+理由；三档预期必带触发条件；红队三视角必过。
7. 概念 5 层：定义→原理→机制→操作→反例；Agent 概念给定义卡。
8. 附属节制：网感/公众号点名才用，不稀释学术标准。

## RSI 递归自决策与自进化闭环（v3.2 补充）

> 系统「自进化」的安全引擎：**自评估 → 自修正 → 自升级** 三层递归，每层有人工闸门。

```
环1 单任务（分钟~小时）：执行 → 验证 → REPAIR（先修后写 ≤10%）→ 复测
环2 周度（AAR 归因）：数据 → 归因 → 权重校准 → 写回基线
环3 月度（版本迭代）：evals 回归 → SKILL 更新 → RELEASE → BETTER
RSI 递归：自评估（evals 10-prompt）→ 自修正（REPAIR，禁改本体）→ 自升级（人做闸门）→ 升级后全量回归
```

- **自动化载体**：每日雷达 08:00 / 预警 09:00 / 归因 周一 / 战略 每月 1 号——已带自进化反馈步骤（TRACE 沉淀到自动化 memory）。
- **双模型分工**（马赛克路由）：`deepseek-v4-flash` 执行轻活（情报/验证/复盘）+ `deepseek-v4-pro` 推理重活（定目标/选战场/定打法），API 已验证。
- **边界**：LLM 提议、人放行；SKILL/prompt/模型配置变更必须人工确认；一切变更走 TRACE 可审计、可回滚。
